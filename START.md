# START — вход в проект (роутер по ролям)

> Ты в проекте на скелете **ProjectStarter**. Определи СВОЮ роль → иди в её файл `Role__*`.
> Читай только свою полосу (разгрузка, не наполнение). Маркеры скелета: `START.md`, `Role__*`, `_hq/`, `_map/`.

## Универсальные правила (коротко)

- Правишь `.py` → в ТОМ ЖЕ заходе обнови карточку `_map/cards/<file>.py.md`.
- Прогресс — аппендом в хвост `_hq/TRACKER.md` (`✅ … → следующий …`); читать только ХВОСТ.
- Адрес узла = имя файла `<координаты-через-«-»>__<slug>.md` (напр. `Plan01-Task03__extract.md`).
  Разбор: `split("__")[0].split("-")`. Теги: `Plan · Task · Context · Vision · Role` (`Design` — резерв).

## Роутинг: твоя роль → файл

| Что делаешь | Грейд | Иди в |
|---|---|---|
| Картируешь проект (карта заголовков/карточки) | сильный | `Role__CodeMap.md` |
| — то же | слабый / локальный | `Role__CodeMapLocal.md` |
| Планируешь (вижен / планы) | сильный + человек | `Role__Plan.md` |
| Исполняешь таск | любой | `Role__Exec.md` |

У каждого `Role__*` — свой метод + свой restore.
**Восстанавливаешься после обрыва?** → `CONTEXT_RESTORE.md` (магнит: определит роль → её restore).
