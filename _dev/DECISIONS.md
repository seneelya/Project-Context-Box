# DECISIONS — решённые калы по РАЗРАБОТКЕ шаблона ProjectStarter

> Это НЕ шаблонный `_HQ/DECISIONS.md` (тот — пустой скаффолд для downstream-проектов). Здесь —
> закрытые решения про **сам продукт** (скелет ProjectStarter). Одна строка = решение + почему.
> Читать перед тем как что-то менять фундаментально; не релитигировать.

- **Рабочие файлы разработки шаблона живут в `_dev/`, не в `_HQ/`** — `_HQ/` это шаблон-продукт,
  копируемый в чужие проекты чистым; наши decisions/tracker/plans/vision его бы засорили. Bootstrap
  копирует продукт (`_HQ/`, `_map/`, программы), `_dev/` пропускает. Имя `_dev` (а не `__HQ`) —
  лексически отдельное от `_HQ`, чтобы не слипалось в grep/сортировке.
