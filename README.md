# ProjectStarter

Универсальный скелет для работы ИИ-агентов над проектом: **роутинг по ролям** + атомарные
планы/таски/карточки, рассчитанные на **слабую/локальную модель** (принцип — *разгрузка агента,
не наполнение*).

- **Вход:** `START.md` — роутер: роль(×грейд) → файл `Role__*`.
- **Мост:** `AGENTS.md` — тонкий, авто-грузится харнесом, шлёт к `START.md`.
- **Роли (в корне):** `Role__CodeMap` / `Role__CodeMapLocal` (картирование сильным/слабым) ·
  `Role__Plan` · `Role__Exec`. У каждой — свой метод + свой restore.
- **Штаб `_hq/`:** `vision/` (зачем/дизайн) · `plans/` (планы+таски, `done/`+`superseded/`) · `TRACKER.md`.
- **`_map/`:** метод картирования (`pass1/2`, `check_freshness.py`, `helpers/`) + `cards/`.

Скелет **копируется вручную** в целевой проект (пустой или чужой). Происхождение: выделено из
memohood, обкатывается здесь и наполняется постепенно.
