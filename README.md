# ProjectStarter

Универсальный скелет для работы ИИ-агентов над проектом: **роутинг по ролям** + атомарные
планы/таски/карточки, рассчитанные на **слабую/локальную модель** (принцип — *разгрузка агента,
не наполнение*).

- **Вход:** `START.md` (роутер трёх веток: Картирование · Планирование · Исполнение).
- **Мост:** `AGENTS.md` — тонкий, авто-грузится, шлёт к `START.md`.
- **Структура:** `_VISION/` (зачем/дизайн) · `_Plan/plans/` (планы+таски, `done/`+`superseded/`) · `_map/cards/` (карта кода).

Скелет **копируется вручную** в целевой проект (пустой или чужой). Происхождение: выделено из
memohood (`_VISION/WIP/task-infra-DRAFT.md`), обкатывается здесь и будет наполняться постепенно.
