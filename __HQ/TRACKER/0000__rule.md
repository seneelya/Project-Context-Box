# Правило папки TRACKER

Этот файл — не запись. Его не архивируют и с него не берут номер и хвост.
Та же норма: `__HQ/guides/Guide__Tracker.md`. Файла `TRACKER.md` нет.

```
__HQ/TRACKER/0042__Plan16-Task05-closed.md
```

**Имя.** Четыре цифры с нулями, только вверх. Пятая цифра встанет раньше `9999`.
Следующий номер — на единицу больше самой новой записи в корне. `0000` не считается.
Записей ещё нет → `0001`. Слаг латиницей: адрес и исход (`Plan16-Task05-closed`),
не дата и не `notes` / `update` / `session`. Несколько исходов — несколько файлов.
Поправка — новый файл.

**Внутри.** Один тезис, файл читается целиком. Маркер по-английски:
`◐ <address>` · `✅ <address> done → next <address>` · `⏸ <address> — <why>`.
Последняя строка всегда `→ next <address>`, её копируют из самой новой записи.
Целиком отложенная цепочка уезжает в `__HQ/plans/deferred/`, это не файл `⏸`.

**Читать.** Только самый новый файл записи в корне.

**Архив.** Больше ~40 файлов в корне — самые старые по номеру переносят в
`__HQ/TRACKER/archive/` как есть. Самая новая запись остаётся. `0000__rule.md` остаётся.
