# Guide: Language — which language for what

**Instructions are English. Everything else is in the owner's language.**

- **English** — whatever an agent acts on: roles, guides, HowTo, START / CONTEXT_RESTORE, the
  procedure of a task (read-list, steps, contract, acceptance), tracker marker lines, cards
  (`__HQ/__map/`), tool docs, code, code comments, commit messages.
- **Owner's language** — the rest: chat with the owner, vision, the goal / why of a plan or task,
  reports and summaries for the owner, notes and discussion.

Mixed file (a task) → the hard parts English, the creative substance in the owner's language
(`Guide__Task.md`). Unsure → English.
